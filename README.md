### `~$ whoami`

CS at **Franciscan University of Steubenville**, class of 2029.

I mostly build things that talk to hardware, or to the network at a layer lower than
they probably need to. Recent evidence: a Rust tunnel that makes a Quest 3 act as a
Windows PC's network card, a falling-sand sim running entirely on the GPU, and a disk
scanner that walks a filesystem faster than the obvious approach because
`FileManager` turned out to be the bottleneck.

Offensive security is the thread through most of it. I like knowing how a thing
actually works, which usually means taking it apart first.
